# Corrigés des exercices

Un dossier par chapitre. Chaque corrigé est un script exécutable, à lancer depuis la racine du dépôt une fois les données préparées :

```bash
uv run python exercises/chapter_02/exercise_1.py
```

Les corrigés supposent que vous avez exécuté les deux scripts de préparation :

```bash
uv run python scripts/prepare_dataset.py
uv run python scripts/build_chapter2_sources.py
```

Un corrigé n'est pas la seule réponse valable. Quand plusieurs approches se défendent, le fichier le signale en commentaire et explique le choix retenu.
